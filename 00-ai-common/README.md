# 📚 AI 基础

介绍人工智能的核心概念、主要分支（机器学习、深度学习、NLP）、发展历程以及在软件开发中的应用场景。

- 难度：入门
- 标签：基础概念
- 状态：✅ 已完成

### 02. 提示词工程基础

学习如何编写有效的提示词，掌握与 LLM 交互的核心原则和高级技巧，提升 AI 输出质量。

- 难度：进阶
- 标签：提示词
- 状态：✅ 已完成

### 03. LLM Agent 入门

了解基于大语言模型的 Agent 架构，学习构建 AI 智能体的核心组件和主流框架。

- 难度：进阶
- 标签：Agent
- 状态：✅ 已完成

### 04. RAG 技术概述

检索增强生成（RAG）技术原理、实现方式以及在企业知识管理中的应用。

- 难度：进阶
- 标签：RAG
- 状态：✅ 已完成

### 05. LLM 微调入门

学习如何对大语言模型进行微调，以适应特定领域或任务需求。涵盖 LoRA、QLoRA 等参数高效微调技术。

- 难度：高级
- 标签：微调
- 状态：✅ 已完成

### 06. AI 软件开发核心概念与 DevOps 实践

用通俗类比、流程图和真实故障修复案例理解 Prompt、斜杠命令、Instructions、Skill、MCP、Agent 与 Subagent，并学习安全护栏和评估方法。

- 难度：入门
- 标签：AI 软件开发、Agent、MCP、DevOps
- 状态：✅ 已完成
