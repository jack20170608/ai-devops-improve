# AI Vibe Coding 系列文章

> 探索 AI 辅助编程的最佳实践，释放创造力，提升开发效率

## 系列简介

AI Vibe Coding（AI 氛围编程）是一种新兴的编程范式，开发者通过自然语言描述需求，AI 辅助生成代码。这种方式改变了传统的软件开发流程，让我们能够更专注于业务逻辑和创新，而非繁琐的代码细节。

本系列文章将从项目结构、代码设计规范、代码评审和测试三个维度，深入探讨 AI vibe coding 的最佳实践，帮助你成为 AI 时代的高效开发者。

- **目录结构**：清晰的分层架构和语义化命名是 AI 理解代码的基础

- **评审测试**：人类审查 + AI 辅助测试 = 高质量代码
